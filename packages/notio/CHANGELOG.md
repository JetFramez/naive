# notio

## 0.2.0

### Minor Changes

- fad8ae4: First release of `notio`: a typed, chainable router on Express 5 with Standard Schema validation, a per-request context, unified errors, lifecycle hooks, structured logging on pino, config, events, cache, and `createApp`. Optional modules at their own subpaths: `./auth` (sessions, JWT, opaque tokens with rotation, password hashing), `./upload` (multipart parsing with content-sniffed type detection), `./rate-limit` (fixed window, sliding window, token bucket), and `./openapi` (OpenAPI 3.1 generation with a Scalar UI).
